Privacy Does it connect to my bank?

No. Larpmaxxing is a browser-only simulator. It cannot see, send, hold, or receive real money.

Your saved setup contains only the fictional name, number, mood, and selected screen.

Creating Can I save a setup?

Yes. Save setup stores the current fictional scene in this browser so it is ready when you return.

Nothing is uploaded and no account is required.

Filming What is focus mode?

It gives the fictional device the whole screen, hiding setup controls while keeping the prop label visible.

Press Escape or use Exit preview to return to the studio.

Use What is off-limits?

Do not use a simulated screen as evidence in a purchase, application, investment, payment, or identity claim.

Creative fiction is the feature. Financial deception is not.
